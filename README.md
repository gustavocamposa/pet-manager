#  Pet Manager

A **Full Stack application for pet management**, built with **React, Node.js, and Express**.

This project was developed as a practical challenge focused on building a complete application with **authentication, authorization, CRUD operations, REST APIs, data validation, and JSON-based data persistence**.

##  Technologies

* React
* Node.js
* Express
* JWT
* LowDB / JSON
* JavaScript

##  Features

* User registration and authentication
* JWT-based login
* User profile management
* Pet registration
* Pet listing
* Pet editing
* Pet deletion
* Data validation
* Protected routes
* Resource authorization
* JSON-based data persistence

##  Security

Each user can only access and manage their own pets.

Authorization is handled on the **backend**, ensuring that users cannot view, edit, or delete pets belonging to other users.

##  Purpose

The main goal of this project is to practice and demonstrate core **Full Stack development concepts**, including frontend and backend integration, REST API development, authentication, authorization, data persistence, validation, and code organization.

The interface is intentionally simple and functional, with the main focus being the application's **logic, architecture, and functionality**.
